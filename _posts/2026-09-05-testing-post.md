In the modern day of agents, vibe coding, TikTok tech influencers, and attention-seeking chumps, we are introduced to a new service called **Programming as Slop**.

Programming / coding / building a 6-figure app / next Y Combinator-funded startup / TikTok low-life Claude addicts

are all just side effects of the modern social media attention-gambling buzzwords being thrown around left and right, on the premise of making you a 6-figure salary or turning you into the next tech founder.

It's a shame that this is what the space is about now, and it's a shame what happened to it in the span of just a few years, starting with the overhiring during COVID, to making everyone learn how to "code," to whatever pyramid scheme they are selling you today.

Every time I go on YouTube to watch something tech-related, all I find is pure slop, pure attention-grabbing garbage.

Every time I go on X, it sounds like a competition for the worst takes ever.

It's all attention-seeking garbage with no real benefit or essence.

And maybe it's my mistake for looking for something meaningful in social media, but still, every time I'm greeted with any of this stupidity, any of these stupid takes, or merely the words that someone decided to put next to each other with the sole goal of making someone gag while reading whatever they are saying.

And maybe that's the real problem. The means have become the product.

Programming used to be: _I want to build something, so I need to understand computers, and I need to learn how to build it._

Now it's: _I want attention, so I need a technological narrative that gets attention._

And then it becomes: _I want money, so I need to sell the dream._

AI + SaaS + agents + passive income + 6 figures + "become a founder."

The software itself almost becomes incidental.

And don't get me wrong, I'm not against AI-assisted programming. Using Claude to help you write software doesn't magically make what you're doing not software engineering.

If you use Claude to help you understand an unfamiliar API, investigate a bug, write tests, refactor some ugly code, or implement something you already understand, you're still engineering software.

The problem is when the understanding is replaced with output.

When you tell Claude, _"build me a SaaS that makes $10k a month,"_ accept whatever comes out, deploy it, and then call yourself a software engineer because you managed to get an AI to produce 20,000 lines of code.

That's not the same thing.

Building software with Claude isn't inherently not software engineering. **Building software without understanding what the fuck you're building is.**

There is a difference between:

_"I used Claude to help me engineer a system."_

and:

_"I told Claude what app I wanted and accepted whatever came out."_

The second one is much closer to what I mean by **Programming as Slop**.

Because programming isn't just producing code.

Software engineering isn't just making something that runs.

It's understanding the system you're building, knowing why it works, knowing why it doesn't work when it breaks, being able to reason about its behavior, understanding its trade-offs, and having enough knowledge to tell when the code you're looking at is complete garbage.

You can't vibe-code your way into understanding why a condition variable releases a mutex while waiting.

You can't genuinely understand an inverted index because Claude generated an `unordered_map<string, vector<uint64_t>>` for you.

You can't learn systems programming by memorizing generated code.

At some point you have to build the mental model yourself.

And that's the part I think we're slowly losing.

The technology has become so accessible that the ability to produce an output is being confused with the ability to understand the thing being produced.

And social media makes this ten times worse because the thing that gets rewarded isn't necessarily understanding.

It's engagement.

A 45-minute explanation of memory ordering, cache locality, or why a particular concurrency bug happens is never going to compete with:

**"THIS AI AGENT JUST REPLACED 10 SOFTWARE ENGINEERS 🤯"**

The latter gives you fear, curiosity, outrage, and aspiration in one fucking thumbnail.

So that's what gets produced.

And then we wonder why every tech feed feels like the same five buzzwords being thrown into a blender.

Agents.

Vibe coding.

SaaS.

Founder.

AI engineer.

10x developer.

6 figures.

Passive income.

Build in public.

Repeat.

Repeat.

Repeat.

It's programming turned into content.

It's software engineering turned into a lifestyle.

And technology turned into a fucking casino where everyone is gambling for attention.

Programming is supposed to be about understanding machines.

Software engineering is supposed to be about building things that actually work.

And learning this shit is supposed to involve actually **learning this shit.**

No, generating code isn't inherently programming as slop.

But confusing generated output with understanding?

**That's programming as slop.**
